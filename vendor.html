벤더별 통합표에 작성하거나 엑셀을 불러오고, 검토 후 공유 저장하세요. 금액은 K USD입니다.

입력 방법과 열 설명

한 파일의 ‘통합입력’ 표로 관리합니다. 표시 구분을 선택하면 해당 열만 보입니다. 엑셀에서 복사한 여러 셀을 웹 표에 붙여넣을 수도 있습니다. 날짜는 YYYY-MM-DD, 금액은 천 달러(K USD)입니다.

  • 분기 실적: Q 시작일·집계일·신규/리뉴얼·실적·타겟. 신규와 리뉴얼의 집계일을 맞추면 합계와 비율을 계산합니다.
  • 연간 실적: FY 시작일·집계일·전체 합계·타겟 유무·누적 실적. 타겟 없는 벤더는 ‘없음’을 선택하세요.
  • 파트너: Q 시작일·집계일·등록/활성/신규 활성/재활성·인정 기준.
  • 프로모션: 한 목표당 한 행. ‘목표 추가’로 같은 프로모션의 목표를 늘립니다. 같은 ID의 행은 기간·스킴 등을 동일하게 유지하세요. 캘린더에서 직접 등록한 프로모션은 프로모션 상세에서 수정합니다.
  • 리드·액션플랜·커뮤니케이션: 한 건당 한 행. 요청을 수정하거나 완료할 때는 ‘이번 대응 내용’을 작성하세요.
  • 기존 데이터를 수정할 때는 현재 표를 내려받으세요. 숨겨진 데이터ID와 수정기준 열은 유지하세요. 빈칸은 미입력으로 저장하며, 값이 0이면 숫자 0을 입력하세요.
  • 표에서 제외는 공유 자료 삭제가 아닙니다. 프로모션 목표 행을 제외하면 저장 시 해당 프로모션의 목표 구성이 바뀌므로 검토 내용을 확인하세요.
